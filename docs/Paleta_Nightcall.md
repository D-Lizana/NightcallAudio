# Paleta visual de Nightcall

La paleta parte de los colores dominantes del logotipo: sombras azul-negro, tonos
petróleo y luces rosas. Se han aclarado los acentos cuando es necesario para
mantener el contraste y la legibilidad sobre el tema oscuro.

| Uso | Color | Hexadecimal |
| --- | --- | --- |
| Fondo principal | Azul negro | `#04151D` |
| Superficie | Petróleo oscuro | `#081D26` |
| Superficie elevada | Petróleo | `#15323D` |
| Acción principal | Rosa neón | `#F090A8` |
| Contenedor principal | Magenta oscuro | `#6E1F42` |
| Acción secundaria | Cian luminoso | `#66D4E5` |
| Contenedor secundario | Cian petróleo | `#00505F` |
| Acento terciario | Coral rosado | `#FFB1B7` |
| Texto principal | Blanco rosado | `#F2E7EB` |
| Texto secundario | Gris malva | `#CDBFC5` |

Los roles se definen mediante el esquema de color de Material 3. Así se aplican
automáticamente a botones, controles seleccionados, tarjetas, reproductor,
navegación y demás componentes que consumen colores del tema. El widget utiliza
la misma combinación de superficie petróleo, texto claro y controles rosas.
